## 二、固定结构（无需改）

### 选品框架
- **双核模式**：销量第1 + 第2款占预算60-70%
- **辅助组**：利润款 + 引流款（凑单/秒杀）
- 选品依据：近30天销量 + 库存深度 + 利润结构

### 活动机制
- **满减**：3梯次，门槛 = 客单价×1.5 / ×2.5 / ×4
- **秒杀**：1款引流款（库存充足）+ 1款清库存（如有）
- **优惠券**：新客无门槛券 + 满减叠加券

### 广告节奏
- 预热（蓄水·测款）→ 爆发前（加曝光）→ 当天（全力冲量）→ 返场（收割）
- 结构：关键字60% + 关联30% + 展示10%
- 预算分配 ≈ 15% / 20% / 25% / 40%

### 话术三件套
- 预热话术：活动预告 + 尺码推荐 + 物流 + 退换
- 大促当天：满减引导 + 秒杀倒计时 + 库存紧迫
- 售后：改地址 + 换货 + 退款 + 质量问题

### 监控
- 每日两次推送（09:00 / 18:00）
- 异常实时告警（GMV偏离目标 >30%）

## 三、注意点（踩过的坑）
- 改价5分钟生效，对买家实时可见
- 秒杀活动发布后不可取消
- 广告钱包余额要提前充值（我不经手资金）
- 满减门槛要覆盖主力款的组合价
- 尺码提醒可降退货率（尤其跨境尺码差异）
